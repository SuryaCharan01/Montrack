# Montrack (₹)

A minimalist, mobile-first, **100% offline** personal expense tracker built with vanilla HTML, CSS, JavaScript, and IndexedDB.

## Features
- **Zero-Latency Entry & Smart Memory**: Remembers frequent/recent places, links merchants to categories, descriptions, and amounts, and provides one-tap quick-log chips.
- **100% Offline & Private**: Stores everything locally in your browser's IndexedDB. Works in Airplane Mode via Service Worker caching.
- **Visual Analytics & Automated Reports**: Interactive HTML5 Canvas charts (Category Donut, Daily Bar, Monthly Trend Line, Top Locations) plus automated weekly/monthly comparison insights.
- **Data Portability**: One-click CSV export (Excel-compatible) and full JSON backup/restore.

## Deploy on GitHub Pages
1. Upload all 6 files to a GitHub repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch** → `main` → `/ (root)` and click **Save**.
4. Open the generated `https://<username>.github.io/<repo>/` URL on your phone and tap **"Add to Home Screen"** (or **"Install App"**) to use it offline like a native app.
